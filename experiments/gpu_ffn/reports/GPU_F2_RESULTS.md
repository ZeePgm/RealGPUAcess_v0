# F2：四层完整 FFN 权重联合实验

日期：2026-11-04。批次：`output/gpu-ffn/20261104-f2-001/`。**F2 已实现并实际运行通过；后续 [F3](GPU_F3_RESULTS.md) 已完成并通过全 FFN 验证。**

## 条件与配对依据

Qwen3-0.6B F16 GGUF，RTX 5070，原 44-token 输入，greedy 生成 8 个非 EOS 输出。KV 继续使用原生 GPU F16 路径。HBF 覆盖第 0、10、20、27 层的完整 gate/up/down，共 12 个矩阵、72 MiB；FFN norm 和其他模型权重不接入本轮 HBF。

使用与 [F1](GPU_F1_RESULTS.md) 相同的 512 MiB HBF 几何、时延、调度及缓冲预算，保留全 FFN 布局中的原始 Global 地址。F1 的三个矩阵在 F2 中地址不变。每例新 Session，只普通写初始化实际登记的 72 MiB，初始化之后取请求 t0。

本批次仅新增一次 F2 联合 GPU 运行，没有重新执行 native 或改变计算轨迹。入口校验了模型、prompt、执行设置、GPU 二进制、运行 DLL、编译来源、HBF 配置和参考文件哈希，从 F1 复制 native 记录，并从原始 GPU 活动重新重建核对计算表。

共享计算表 SHA256：`cdb402ec39ea930f7b81d08e12b64bddeeff2a38df314e42c9d26bf7ed4a4799`，18072 个窗口，GPU 活动并集总量 61.983127 ms。模型 SHA256：`74878aba1d10648eae3d6cfef822f8c59ce3217b3808b35fce2dd02d975952a2`。二进制与 F1 完全相同，无需重新编译。
