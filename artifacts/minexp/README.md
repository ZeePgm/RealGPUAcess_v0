克隆或下载 **minexp分支完整仓库**，保留本目录所有102个分片及两个索引。Python标准库即可，不需要CUDA或第三方模块：

```powershell
python artifacts/minexp/restore.py --verify-only
```

将原记录恢复到当前仓库（会重建`output/gpu-s/...`，约4.44GB；现有同哈希文件跳过，冲突文件报错且不覆盖）：

```powershell
python artifacts/minexp/restore.py --destination .
```

